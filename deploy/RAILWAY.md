# Railway deployment

The root Dockerfile builds React and serves the frontend and FastAPI from one HTTPS domain. Set the service root to the repository root, Dockerfile path to /Dockerfile, port 8000 and healthcheck /ready. PostgreSQL and Redis should have persistent volumes and no public domains or TCP proxies. Configure APP_ENV=production, a random APP_SECRET_KEY, a PostgreSQL SQLAlchemy URL using postgresql+psycopg://, REDIS_URL, the exact public domain in TRUSTED_HOSTS and CORS_ORIGINS, and the initial administrator email/password using Railway Variables. Also allow healthcheck.railway.app and localhost in TRUSTED_HOSTS. Do not commit secrets. Startup applies Alembic migrations. Use the HTTPS website for login and administration. Remove the bootstrap password variable after initial setup and provide a secure password change process before admitting real customer data. The existing separate Docker Compose setup remains supported.
